# Curve-TrueValue

After Effects 用 CEP パネル。CSS の `cubic-bezier()` と同じ 0-1 正規化座標でカーブを編集し、選択したキーフレームにイーズを適用します。

---

## 解決する問題

| AE の問題 | 本パネルの対処 |
|---|---|
| 速度グラフが直感的でない（値ではなく速度を表示） | Figma / CSS スタイルの 0-1 正規化 cubic-bezier で編集 |
| ブーメラン効果（空間補完が自動的に曲がる） | 「空間補完をリニアに」オプションで自動無効化 |
| Position の X/Y が同じカーブになる | 「次元を分割」オプションで `dimensionsSeparated` を自動設定 |

---

## 動作環境

- **After Effects CC 2019 以降**（バージョン 16.0+）
- Windows / macOS

---

## インストール

### 1. CEP デバッグモードを有効化（初回のみ）

**Windows（PowerShell を管理者で実行）:**
```powershell
reg add "HKCU\Software\Adobe\CSXS.11" /v PlayerDebugMode /t REG_SZ /d 1 /f
reg add "HKCU\Software\Adobe\CSXS.10" /v PlayerDebugMode /t REG_SZ /d 1 /f
```

**macOS（ターミナル）:**
```bash
defaults write com.adobe.CSXS.11 PlayerDebugMode 1
defaults write com.adobe.CSXS.10 PlayerDebugMode 1
```

### 2. 拡張フォルダに配置

リポジトリのフォルダを AE の CEP 拡張フォルダにコピーまたはシンボリックリンクで配置します。

**配置先パス:**

| OS | パス |
|---|---|
| Windows | `C:\Users\ユーザー名\AppData\Roaming\Adobe\CEP\extensions\com.o3x.curve-truevalue` |
| macOS | `~/Library/Application Support/Adobe/CEP/extensions/com.o3x.curve-truevalue` |

**Windows（シンボリックリンクで配置する場合）:**
```powershell
New-Item -ItemType Directory -Path "$env:APPDATA\Adobe\CEP\extensions" -Force
New-Item -ItemType SymbolicLink `
    -Path "$env:APPDATA\Adobe\CEP\extensions\com.o3x.curve-truevalue" `
    -Target "リポジトリのパス"
```

### 3. AE を再起動

**ウィンドウ → 拡張機能 → Curve-TrueValue** でパネルが表示されます。

## 基本的な使い方

### シングルセグメント（2点カーブ）

1. タイムライン上でキーフレームを **隣接する 2 点** 選択する
2. パネルのカーブエディタでカーブを調整する（またはプリセットを選ぶ）
3. **「選択KFに適用」** ボタンを押す

### 複数セグメント（多点カーブ）

1. タイムライン上でキーフレームを **2 点** 選択する（適用範囲の始点と終点）
2. カーブエディタにノードを追加して複雑なカーブを作る
3. **「選択KFに適用」** ボタンを押す

> 中間ノードは選択した 2 つのキーフレームの間に **新しいキーフレームとして自動挿入** されます。

---

## カーブエディタの操作

```
Y
1.0 ┤         ╭───●  ← P2（シアン、終点ハンドル）
    │      ╭──╯
    │   ╭──╯
0.0 ┤ ──╯
    │ ↑ P1（オレンジ、始点ハンドル）
    └──────────────── X
   0.0              1.0
```

| 操作 | 動作 |
|---|---|
| ハンドルをドラッグ | カーブの形状を変更 |
| アンカー（ノード）をドラッグ | 中間ノードの位置を移動 |
| カーブ上をダブルクリック | その位置にノードを追加（De Casteljau 分割、カーブ形状を維持） |
| ノードをクリック | ノードを選択 |
| **Alt + ノードをクリック** | スムーズ / コーナーを切替 |

### ノードの種類

| 表示 | 種類 | 動作 |
|---|---|---|
| ● 円 | スムーズ | 左右のハンドルが連動してミラー移動（C1 連続） |
| ■ 四角 | コーナー | 左右のハンドルが独立して動く（カスプ） |

## パネルの各コントロール

### P1 / P2 入力（シングルセグメント時のみ表示）

カーブの始点ハンドル（P1・オレンジ）と終点ハンドル（P2・シアン）の座標を数値で直接入力できます。

- X: 時間方向の影響度（0〜1）
- Y: 値方向の位置（0 = 始点値、1 = 終点値）

### ノードコントロール（中間ノード選択時のみ表示）

中間ノードを選択すると表示されます。

| コントロール | 説明 |
|---|---|
| ◯ スムーズ | ハンドルをリンク（なめらかな曲線） |
| ◇ コーナー | ハンドルを独立（急激な方向転換） |
| 削除 | 選択中の中間ノードを削除 |
| A  X / Y | アンカー（ノード）の座標を精密入力 |
| ● Y（オレンジ） | handleOut（次セグメントへの出口ハンドル）の Y 座標 |
| ● Y（シアン） | handleIn（前セグメントからの入口ハンドル）の Y 座標 |

> 精密入力欄は Y=0 や Y=1 にぴったり合わせたいときに使います。カーブのドラッグ操作だけでは正確に 0.00 / 1.00 に合わせにくいためです。

### CSS cubic-bezier 表示（シングルセグメント時のみ表示）

現在のカーブを CSS の `cubic-bezier()` 形式で表示します。Web アニメーションのイーズ値と直接対応します。

### プリセット

| プリセット | P1 | P2 |
|---|---|---|
| Linear | (0.00, 0.00) | (1.00, 1.00) |
| Ease | (0.25, 0.10) | (0.25, 1.00) |
| Ease In | (0.42, 0.00) | (1.00, 1.00) |
| Ease Out | (0.00, 0.00) | (0.58, 1.00) |
| Ease In Out | (0.42, 0.00) | (0.58, 1.00) |
| AE Default | (0.33, 0.00) | (0.67, 1.00) |
| Overshoot | (0.34, 1.56) | (0.64, 1.00) |
| Anticipate | (0.38, −0.40) | (0.61, 1.00) |
| Bounce Out | (0.22, 1.20) | (0.36, 1.00) |

### オプション

| オプション | 説明 |
|---|---|
| **空間補完をリニアに（ブーメラン防止）** | Position プロパティの空間補完を Linear に設定し、ブーメラン効果を防ぐ。デフォルト ON |
| **次元を分割（Position）** | Position プロパティの `dimensionsSeparated` を `true` に設定。X/Y を別々のカーブで制御できる |

---

## ヒント

- **Y 軸はオーバーシュート可能**です（−0.5〜1.5 の範囲）。Bounce や Overshoot プリセットがその例です。
- **X 軸は時間軸**のため、中間ノードが同じ X 座標に重なることはできません。ドラッグ時に自動的に制限されます。
- 「空間補完をリニアに」は Position 以外のプロパティには無視されます（エラーになりません）。
- 多点カーブを適用すると元の KF の間に新しい KF が挿入されます。**Ctrl+Z で元に戻せます**。
- AE 上でパネルを右クリック → Inspect Element から DevTools でデバッグできます（デバッグモード有効時のみ）。
